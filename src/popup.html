Feed Declutter

Triages your LinkedIn feed. Local-first, with optional AI + memory.

Lower = filters more posts. Higher = only the obvious ones.

Off by default. When on, borderline post text is sent to the provider below.

Memory (InsForge)

Stores muted authors + decision log so the agent learns. Blank = local only.

Actions (Rover)

When on, muting an author also asks Rover to unfollow them on LinkedIn. Get config from rtrvr.ai/rover workspace (publicKey only).
